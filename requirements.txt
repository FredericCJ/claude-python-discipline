# What a vendored `.agent/` needs to run, and nothing more.
#
#     pip install -r .agent/requirements.txt
#
# This is the ADOPTER manifest. It is not the environment this discipline is
# maintained in -- that is `environment.yml` upstream, which additionally pins
# ruff, pytest and three pytest plugins for the corpus's own gate. An adopting
# repository runs its own gate against its own code and needs none of that.
#
# Python 3.11 or newer (discipline/fact/py-typing.md).

# tools/nav.py imports build_graph, which imports discipline_core, which parses
# front-matter with PyYAML. The navigator reads a generated JSON graph and never
# parses YAML itself, but the import chain reaches it, so it is required rather
# than optional.
PyYAML==6.0.3

# tools/validate.py checks module front-matter against tools/frontmatter.schema.json.
# Needed only if you validate the corpus; harmless otherwise.
jsonschema==4.26.0

# NOT required, and deliberately not listed as such:
#
#   tools/learn.py       standard library only
#   tools/integrate.py   standard library only
#   tools/vendor.py      standard library only
#
# Those three are what an adopter uses most -- announcing the discipline,
# recording what a session learned, and updating the vendored copy -- so the
# common path needs no installation at all.
#
# tiktoken is NOT required. tools/build_index.py measures the `tokens:` field
# with a character-ratio estimate defined in tools/discipline_core.py, so its
# output is the same on every machine. An earlier version imported tiktoken when
# present and estimated when absent, which made generated bytes depend on what
# happened to be installed.
